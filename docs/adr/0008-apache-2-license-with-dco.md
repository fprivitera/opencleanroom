# Apache-2.0 with SPDX headers and DCO sign-off

The project is licensed under Apache-2.0 for its explicit patent grant, the same license as Spark and Tumult Analytics. `LICENSE` and `NOTICE` sit at the root, each source file carries one `SPDX-License-Identifier: Apache-2.0` line, and contributions are accepted with a DCO `Signed-off-by` line instead of a CLA, which keeps the barrier to outside contributors low.
